FANTASY RPG ICON FREE SAMPLER
=============================

A free collection of 20 fantasy icons for inventories, loot tables, crafting
menus, shops and other game UI. These icons are selected from the complete
160-icon Fantasy RPG Icon Pack.

Sampler page:

    https://lukeultra.itch.io/20-free-fantasy-rpg-inventory-icons

WHAT'S INCLUDED
---------------
- 20 unique icons
- Five sizes: 1024, 512, 256, 128 and 64 pixels
- Transparent PNG backgrounds
- The same filenames in every size folder
- A 1280 x 1024 spritesheet using 256-pixel cells
- JSON frame coordinates for all 20 sprites
- An icons.json manifest with full-pack index, filename, display name and category
- A human-readable CONTENTS.md catalogue
- A contact sheet for browsing the sampler

There are 100 ready-to-use PNG files in total. They are in the PNG folder,
sorted by size.

For atlas-based rendering, load spritesheet.png once and use spritesheet.json
to select each icon's 256 x 256 source rectangle. icons.json provides the
complete item manifest, while CONTENTS.md provides the same catalogue in a
human-readable format.

USING THE ICONS
---------------
Pick the size that best suits your project and drop the files into your engine
or editor. Because the filenames match across all five folders, you can swap
sizes later without renaming your asset references.
